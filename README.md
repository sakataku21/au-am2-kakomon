# AU 午前Ⅱ 過去問演習

システム監査技術者試験（AU）午前Ⅱの過去問を、1問ずつ解いてその場で正解と解説を確認できるWebアプリです。

- 収録：平成31年度春期、令和2年度10月、令和3〜7年度秋期の7回分（各25問、計175問）
- トップページで回・出題順（番号順／ランダム）・範囲（全問／前回間違えた問題）を選んで出題開始
- 1問ごとに正誤・解説・参考リンクを表示し、最後に25問の結果と間違えた問題の解き直しを表示
- 結果画面に正答率を表示し、同じ回の前回（本番）との差も表示。トップページには回ごとの前回の正答率を表示
- 受験ごとの記録（各問の正誤・分野・解答秒数）をブラウザに保存し、設定すればGoogleスプレッドシートにも追記。Looker Studioで正答率の推移や分野別の弱点をグラフにできる（手順は [SETUP.md](SETUP.md)）
- 途中経過はブラウザ（localStorage）に保存

## 出典

問題・正解は、独立行政法人情報処理推進機構（IPA）が公開しているシステム監査技術者試験 午前Ⅱの問題冊子・解答例を使用しています。問題は問題冊子から問ごとに画像として切り出しています。各問の出典は画面上に「出典：令和7年度 秋期 システム監査技術者試験 午前Ⅱ 問1」の形式で表示しています。

- IPA 過去問題：https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html

解説は、Web上の解説サイト（IPA Advanced：ipa.kinocode.jp、サクトレWeb：systemauditengineer.sakutore.decryption.co.jp）の各問の解説と、経済産業省「システム監査基準」などの原典を照合し、本アプリで要約・再構成したものです。解説文の転載はしていません。IPAの公式な解説ではありません。参考にした解説・資料は各問の解説の下にリンクで示しています。

## ファイル構成

- `index.html` / `style.css` / `app.js`：アプリ本体（ビルド不要の静的サイト）
- `data.js`：各問の正解・解説・参考にした解説・資料のリンク
- `img/<回>/qNN.png`：問題画像
- `gas/Code.gs`：学習記録をスプレッドシートに書き込む Google Apps Script（トークンはスクリプト プロパティに保存し、コードには含まない）
- `SETUP.md`：学習記録と Looker Studio の設定手順
